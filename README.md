# NexusMart Enterprise — Modern React E-Commerce Platform

![React](https://img.shields.io/badge/React-19-blue.svg)
![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue.svg)
![Vite](https://img.shields.io/badge/Vite-8.x-purple.svg)
![Design](https://img.shields.io/badge/UI-Modern%20Glassmorphism-emerald.svg)

NexusMart Enterprise is a modern, fast, responsive single-page e-commerce web application built using **React 19**, **TypeScript**, **Vite**, and **Lucide Icons**, with full state management, persistent mock database engine, customer portal, administrative control suite, and AI customer support assistant.

---

## 🚀 Key Features

* **⚡ Storefront Experience**:
  * Hero showcase carousel with promo alerts and ambient effects.
  * Multi-filter product catalog (category, brand, price slider, rating, search, grid/list view).
  * Product details with high-res multi-image gallery zoom and live customer review submissions.
  * Slide-out animated Cart Drawer with promo discount coupons (`SUPER20`, `NEXUS10`, `WELCOME500`).
  * Customer saved wishlist with 1-click move to cart.
  * Multi-method checkout (Credit/Debit Card with live card preview, Cash on Delivery, Instant UPI QR Code).
  * Milestone delivery timeline tracking (`/my-orders`).
  * 24/7 **NexusAI** intelligent customer support assistant widget.

* **🛡️ Admin Control Suite (`/admin`)**:
  * Real-time sales analytics and inventory alert dashboard.
  * Full product catalog manager with stock adjustments and image URL support.
  * Category and Brand CRUD managers.
  * Order fulfillment management with live delivery status updater.
  * Store valuation and revenue reporting.

---

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** or **`http://localhost:5174/`** in your browser.

### 3. Build for Production
```bash
npm run build
```
